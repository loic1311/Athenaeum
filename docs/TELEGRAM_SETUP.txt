ATHENAEUM BOT - TELEGRAM SETUP

DOEL
Athenaeum Bot kan bijvoorbeeld sturen:
- iedere ochtend: dagnummer, streak, ijsblokjes, 20 min Oude Geschiedenis + 10 min Algemene Geschiedenis, extra sessie indien van toepassing;
- later op de dag: reminder als de dagsessie nog niet voltooid is;
- melding dat zondag een weekexamen volgt;
- examenuitslag / weekly report in latere updates.

WAAROM SERVER-SIDE?
Zet een Telegram bot-token NOOIT in GitHub/JavaScript. Iedereen zou het kunnen uitlezen. Het meegeleverde Supabase Edge Function-sjabloon bewaart het token als secret.

STAP 1 - BOT MAKEN
1. Open Telegram en zoek @BotFather.
2. Stuur /newbot.
3. Kies naam, bijvoorbeeld Athenaeum Bot.
4. Kies een username die eindigt op bot.
5. Bewaar het BOT TOKEN tijdelijk privé.

STAP 2 - SUPABASE
1. Maak 1 gratis Supabase-project voor Athenaeum.
2. SQL Editor > voer ../supabase/setup.sql uit.
3. Deploy de Edge Function uit ../supabase/functions/telegram-bot/index.ts als 'telegram-bot'.
4. Voeg in Edge Function Secrets toe:
   TELEGRAM_BOT_TOKEN = token van BotFather
   ATHENAEUM_APP_URL = jouw GitHub Pages URL, bv. https://jouwnaam.github.io/Athenaeum/

SUPABASE_URL en SUPABASE_SERVICE_ROLE_KEY worden in de hosted Edge Function-omgeving beschikbaar gemaakt. Gebruik service-role key NOOIT in client-JavaScript.

STAP 3 - TELEGRAM WEBHOOK
Open in browser, met jouw echte waarden:
https://api.telegram.org/bot<TELEGRAM_BOT_TOKEN>/setWebhook?url=<SUPABASE_FUNCTION_URL>

Function URL is ongeveer:
https://PROJECTREF.supabase.co/functions/v1/telegram-bot

STAP 4 - ATHENAEUM PROFIEL KOPPELEN
1. In Athenaeum > Instellingen: configureer Supabase en meld aan.
2. Stel ochtendtijd, reminder en timezone in.
3. Klik 'Koppel Athenaeum Bot'.
4. Athenaeum toont een tijdelijke code, bv. AB12CD.
5. Open jouw bot in Telegram en stuur:
   /start AB12CD
6. De bot bevestigt de koppeling.

STAP 5 - DAGELIJKSE SCHEDULER
Supabase kan met pg_cron + pg_net iedere 15 minuten dezelfde Edge Function aanroepen met body:
{"mode":"schedule"}

In setup.sql staat een voorbeeld. Iedere 15 minuten is ruim binnen normale persoonlijke gebruiksschaal en controleert de function zelf of het lokaal in jouw timezone tijd is voor ochtendbericht/reminder. Het bot stuurt per dag maar 1 ochtendbericht en 1 reminder.

PRIVACY
Iedere gebruiker koppelt zijn eigen Athenaeum-profiel en Telegram-chat. De Edge Function gebruikt de gekoppelde chat_id alleen om Athenaeum-meldingen te versturen.
