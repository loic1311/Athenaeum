ATHENAEUM V1.0.3 — TELEGRAM VOOR PAIDEIA

DOEL
- iedere ochtend: dagnummer, streak, ijsblokjes, dagschema en aftelling tot zondagsexamen;
- later op de dag: reminder als Paideia nog niet voltooid is;
- testmelding vanuit Athenaeum of rechtstreeks vanuit Paideia.

1. SUPABASE
Open je bestaande Athenaeum-project en voer supabase/setup.sql uit in SQL Editor.

2. TELEGRAM BOT MAKEN
Open Telegram en chat met @BotFather.
Gebruik /newbot en kies bijvoorbeeld Athenaeum Bot.
Kopieer de bot token. DEZE TOKEN NOOIT IN GITHUB OF DE BROWSERAPP ZETTEN.

3. EDGE FUNCTION DEPLOYEN
Deploy de map supabase/functions/telegram-bot als function 'telegram-bot'. Voor Telegram-webhooks moet de function publiek bereikbaar zijn; deploy daarom zonder automatische JWT-verificatie. De function valideert gebruikerscalls zelf en kan optioneel Telegram's webhook-secret controleren.

Benodigde Supabase secrets:
TELEGRAM_BOT_TOKEN=<token van BotFather>
ATHENAEUM_APP_URL=https://JOUWNAAM.github.io/Athenaeum/
TELEGRAM_WEBHOOK_SECRET=<lange willekeurige tekenreeks>
SCHEDULER_SECRET=<andere lange willekeurige tekenreeks>

SUPABASE_URL en SUPABASE_SERVICE_ROLE_KEY worden in Supabase Edge Functions normaal door het platform beschikbaar gesteld.

4. TELEGRAM WEBHOOK INSTELLEN
Open in je browser (vul BOT_TOKEN, PROJECT_REF en WEBHOOK_SECRET in):
https://api.telegram.org/botBOT_TOKEN/setWebhook?url=https://PROJECT_REF.supabase.co/functions/v1/telegram-bot&secret_token=WEBHOOK_SECRET

Telegram moet {"ok":true} teruggeven.

5. SCHEDULER
Laat de Edge Function elke 15 minuten aanroepen. In setup.sql staat een pg_cron/pg_net voorbeeld. Geef in de request-body mode='schedule' en je SCHEDULER_SECRET mee. De function controleert zelf per profiel of het werkelijk ochtendtijd/remindertijd is.

6. PROFIEL KOPPELEN
Athenaeum > Instellingen > synchronisatie: meld aan met het eigen Supabase-account van die gebruiker.
Daarna: Telegram > Koppel Athenaeum Bot.
Of rechtstreeks in Paideia > Telegram.
Open de gegenereerde Telegram-link of stuur /start CODE naar de bot.

7. TEST
Klik 'Stuur testmelding'. Als die aankomt, werkt bot + Supabase + profielkoppeling.

BELANGRIJK
Elk Athenaeum-profiel hoort voor cloudsynchronisatie bij een eigen Supabase-authaccount/e-mailadres. Iedereen kan hetzelfde Supabase-project gebruiken, maar de RLS-policies zorgen dat gebruikers alleen hun eigen data zien.
