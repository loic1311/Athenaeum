ATHENAEUM V1.0.6 — TELEGRAM VOOR PAIDEIA

Een Telegram-bot-token alleen is NIET voldoende. Athenaeum gebruikt een Supabase Edge Function zodat je geheime bot-token nooit in GitHub of in de browser terechtkomt.

EENMALIG
1. Voer supabase/setup.sql uit in Supabase SQL Editor.
2. Ga in Supabase naar Edge Functions en maak/deploy een functie met naam: telegram-bot.
3. Gebruik de code uit supabase/functions/telegram-bot/index.ts.
4. De functie moet JWT-verificatie op platformniveau UIT hebben; in het pakket staat supabase/config.toml met verify_jwt=false. De functie valideert Athenaeum-gebruikers zelf.
5. Voeg in Supabase Edge Function Secrets toe:
   TELEGRAM_BOT_TOKEN=<token van BotFather>
   ATHENAEUM_APP_URL=https://loic1311.github.io/Athenaeum/
   TELEGRAM_WEBHOOK_SECRET=<lange willekeurige tekst>
   SCHEDULER_SECRET=<andere lange willekeurige tekst>
6. Deploy opnieuw nadat de secrets zijn ingesteld.

WEBHOOK VEILIG INSTELLEN
De V1.0.6 Edge Function ondersteunt mode=setup_webhook. Roep die vanuit de Supabase Function tester aan met:
{"mode":"setup_webhook","secret":"JOUW_SCHEDULER_SECRET"}
De function gebruikt server-side TELEGRAM_BOT_TOKEN en stelt zelf de juiste Telegram-webhook in.

DAARNA
7. Meld in Athenaeum eerst aan bij Cloud.
8. Instellingen → Telegram → Diagnose Telegram. Alles tot en met Edge Function/bot moet groen zijn.
9. Klik Koppel Athenaeum Bot. Open de link of stuur /start CODE naar de bot.
10. Klik Stuur testmelding.

GEPLANDE OCHTENDMELDINGEN
Voor automatische meldingen moet de telegram-bot function periodiek worden aangeroepen. Het voorbeeld staat onderaan supabase/setup.sql. De function beslist zelf per tijdzone of het werkelijk tijd is om te sturen.
