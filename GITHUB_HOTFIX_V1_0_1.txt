ATHENAEUM V1.0.1 — GITHUB HOTFIX

Deze hotfix maakt de hoofdschil failsafe:

- store, sync en hoofd-JavaScript staan rechtstreeks in index.html;

- Paideia is eveneens grotendeels self-contained;
- het volledige Scriptorium V7-pakket zit onder apps/scriptorium/;
